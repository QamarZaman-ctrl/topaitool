# Top AI Tools Blog

A data-driven blogging site about free AI tools, built from keyword research data.

## Quick Start

Open `index.html` in your browser — no build step or server required.

```powershell
Start-Process "C:\Users\offic\OneDrive\Desktop\topaitool\index.html"
```

Or double-click `index.html` in File Explorer.

## What's Inside

- **12 expert blog articles** covering top AI tool categories
- **590+ keywords** from Google Ads keyword research (Aug 2025 – Jul 2026)
- **9 categories**: Image Generators, Chat AI, Open Source, Art Generators, AI Detection, AI APIs, Text & Writing, Learning, General Tools
- **Search & filter** by category or keyword
- **Responsive design** — works on mobile and desktop

## Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage with featured article, categories, latest posts |
| `blog.html` | All articles with category filters and search |
| `post.html?id=...` | Individual article pages |
| `about.html` | About the site and methodology |

## Data Source

Content is derived from `topaitools.txt` — Google Ads keyword stats including:
- Monthly search volumes (up to 500K for "free ai image generator")
- Competition levels
- Year-over-year growth trends (e.g., open source AI +900%)
